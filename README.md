## About KRNL

KRNL is a standalone Windows application for running custom Lua scripts in the Roblox environment. It connects with the Roblox client and enables third-party scripts intended for automation, testing, or gameplay changes. Its workflow is centered on quick injection and an included library of scripts.

The application is designed to accommodate beginners as well as experienced users. It combines a persistent execution pipeline, local storage, and automatic updates in a compact desktop package. KRNL also includes multiple interface languages and batch processing, while remaining free to use without key activation.
